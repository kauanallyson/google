# Google em C:

## REQUESITOS DO PROJETO
- [ ] cadastrar novos sites, palavras-chave e links;
- [ ] remover sites e links existentes;
- [ ] salvar todos os dados em arquivo;
- [ ] carregar uma miniatura da internet previamente salva;
- [ ] pesquisar uma palavra e listar os sites que a contêm;
- [ ] pesquisar mais de uma palavra;
- [ ] realizar consultas utilizando os operadores AND e OR;
- [ ] calcular a importância de cada site pela soma dos valores das arestas que chegam até ele;
- [ ] ordenar os resultados por importância e, em caso de empate, por ordem alfabética;
- [ ] recalcular o ranking após inserção, remoção ou alteração de links.
